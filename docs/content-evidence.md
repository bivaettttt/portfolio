# Реестр доказательств

Снимки и диаграммы личных проектов закреплены к конкретным коммитам в JSON кейсов. Для Traceon, Nexora и Flowent использована графика последних редизайнов. Снимки сохранены в lossless WebP для презентации и в побайтных PNG для галереи. SHA-256 и исходные размеры записаны в JSON. Ссылка на репозиторий закреплена к коммиту.

| Проект | Сценарий | Аналитические материалы |
| --- | --- | --- |
| Traceon | Требование → влияние → решение → baseline | Граф, требования, проверки |
| Nexora | CRM → ERP и Billing → сбой → сверка | Контейнеры, OpenAPI, архитектура и тесты |
| Flowent | BPMN → публикация → JOIN → восстановление | Требования, семантика и последовательность JOIN |
| Vaultix | Перевод → проводки → откат | Схема перевода, OpenAPI, протокол |
| Credence | Заявка → уточнение → независимое решение | Модель и правила, OpenAPI, последовательность |
| Sentrix | Сигнал → расследование → решение | Приём операции, проектирование, трассируемость |
| Wayline | Изменение рейса → риск → альтернатива | Цикл обновления, требования и проверки |
| Quantara | Показатель → происхождение → исправление | Lineage, модель данных, методика |
| Veridion | Вопрос → цитата → версия → ревью | Последовательность вопроса, OpenAPI, известные границы |

Публичные учебные PNG и SVG взяты из проверенной старой публикации. Банковская ERD получена из каталога PostgreSQL после применения DDL. У учебного прототипа личных финансов сохранены два реальных кадра. Локальные PDF-экспорты резюме использованы для проверки сведений, публичной остаётся ссылка на HH.ru. Архивные отчёты и материалы в соавторстве не входят в сборку.

Для нового кадра запустите `npm run media -- original.png public/media/<проект>/<кадр>.webp`. Команда сохраняет локальный PNG и lossless WebP до 1600 px с вариантами 640/960/1280, когда ширина доступна в оригинале. Метаданные, подписи и контрольную сумму необходимо добавить в JSON кейса.

Для Portfolio 2.0 добавлены исходные учебные кадры и три явно подписанные реконструкции. Подробная [классификация материалов и границ](portfolio-2.md#медиа-и-подлинность), [30 оригиналов и размеры](media-quality-audit.md).

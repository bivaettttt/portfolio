# Статус редизайна

Рабочая ветка `codex/editorial-portfolio` содержит Astro-исходники, двуязычный каталог и доказательства. Старый опубликованный сайт используется как исходная точка сравнения. Точная процедура выпуска и результат фиксируются в [проверке релиза](release-verification.md).

Подтверждённые сведения о резюме проверены по локальному экспорту. Публичный контакт — существующие ссылки Telegram, HH.ru и GitHub. У практики и хакатона закрытая исходная графика, поэтому визуальные разделы показывают обезличенное описание процесса. Заявление о полном WCAG 2.2 AA требует отдельной проверки скринридерами и более широкой ручной матрицы.

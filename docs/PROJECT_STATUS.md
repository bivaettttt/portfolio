# Статус Portfolio 2.0

Реализация подготовлена в ветке `codex/portfolio-2`: редакционная главная, контекстная навигация, расширенные 15 кейсов, оригиналы 30 личных кадров, новая галерея и монограмма. Локально пройдены `npm run verify` и 16 Playwright-тестов. Результат публикации и SHA фиксируются в [проверке релиза](release-verification.md).

[Полный отчёт](portfolio-2.md) · [Проверки](testing-results.md) · [До/после](evidence/v2/screenshots.md).

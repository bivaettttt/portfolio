# Проверки

- `npm run verify` проверяет Prettier, Astro и TypeScript, сборку из 77 HTML-страниц, внутренние ссылки, две языковые версии, медиапакет и отсутствие распространённых паттернов секретов. Schema Content Collections валидирует проекты при сборке. Проверка паттернов — ограниченный автоматический фильтр, а не полный аудит истории Git.
- Playwright покрывает reflow на 1920, 1440, 1280, 1024, 768, 390 и 320 px, карьерный путь и переключение языка, анализ требования, API-фильтр, клавиатурную галерею, изображения всех девяти кейсов, темы, reduced motion и axe. Отдельно проверяется старый адрес и открытие оригинального материала без JavaScript.
- 69 ссылок на исходные документы, контракты, диаграммы и снимки сверены через Git с закреплёнными коммитами локальных клонов. Исходники девяти проектов заменять не требуется.
- Playwright MCP использован для аудита исходной сборки и визуальной проверки новой. По результатам просмотра поправлены граница нижнего слоя hero, число кейсов и композиция флагманов.
- [Аудит доступности](accessibility-review.md), [производительность](performance-report.md), [снимки](evidence/after/).

Итог перед публикацией: 4 статические проверки и 13 Playwright-тестов прошли. `astro check` завершился с нулём ошибок и предупреждений.

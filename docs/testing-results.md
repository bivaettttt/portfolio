# Проверки Portfolio 2.0

`npm run verify`: Prettier, Astro/TypeScript (0 ошибок, предупреждений и подсказок), 77 HTML-страниц, 6 статических/медиа тестов — пройдены. Проверяются языковые версии, локальные href/src/srcset/poster, legacy redirects, схема контента, отсутствие распространённых секретов и закрытых расширений в сборке. 30 личных PNG проверены по SHA-256 и размерам; 29 lossless WebP совпадают по декодированным RGB-пикселям, новый Wayline — с уменьшенным оригиналом до 1600 px. Размеры favicon и фрагментов также проверены.

`npm run test:browser`: 16 тестов Chromium — пройдены. Покрытие: 7 ширин (1920/1440/1280/1024/768/390/320), путь рекрутера, тема, reduced motion, требование, OpenAPI-фильтр, оригиналы, галерея и клавиатура, Escape/фокус, мобильный DPR 2, Breadcrumbs, переключатель, deep link, язык и Back/Forward с восстановлением прокрутки. Проверяется legacy-маршрут и исходный материал без JavaScript. Preview запускается с `--ignore-lock`, чтобы агентский режим Astro не завершал webServer преждевременно.

Расширенная матрица: 22 опубликованных маршрута × 7 ширин = 154 открытия, плюс 4 англоязычных/тёмных состояния — 158. Все HTTP 200, document overflow не обнаружен. Повторный проход сохранил 90 замеров изображений: выбранный currentSrc, размеры CSS/intrinsic, DPR, srcset/sizes и переданные байты. [Замеры после](evidence/v2/media-after.json) и [до](evidence/v2/media-before.json).

Визуально просмотрены первые экраны 22 маршрутов, продуктовые разделы девяти личных проектов, учебные материалы и реконструкции практики. Проверены полноэкранные изображения и перетаскивание: смещение области составило 260 px по X и 80 px по Y. Ошибок JavaScript и локальных ответов ≥400 при контрольном проходе не обнаружено. Изначальная диагностическая выборка включала пустой `<img>` закрытого диалога; это не запрос и не повреждённый файл, итоговый проход ограничен изображениями с src.

Первый тест истории поймал ошибку в измерении: координата фиксировалась до завершения языкового перехода. Тест теперь ожидает английский документ и загруженные шрифты и фиксирует положение непосредственно перед уходом. Ослабления требований к сохранению контекста нет. Автоматический axe по 6 маршрутам в 2 темах не обнаружил нарушений заданных правил. [Объём проверки доступности](accessibility-review.md).

Визуальная критика: действия главной перемещены перед документами на телефоне, mobile case switcher уплотнён без потери категории, подписи кадров привязаны к конкретным функциям, стрелка ссылки оригинала собрана в одну строку. Повторный просмотр проводится на production-сборке с декодированными lazy-изображениями; первые технические full-section снимки без предварительной прокрутки не использованы как доказательства пропажи кадров.

Пересъёмка Wayline воспроизведена на отдельном Compose-проекте `wayline-portfolio2`, без изменения кода и прежних данных. Ожидались две видимые поездки и исчезновение «Загрузка…». [Параметры захвата](evidence/v2/wayline-capture.json).

Ограничения: проверки Chromium, без VoiceOver/NVDA и отдельного Safari/Firefox-прогона. Контент и снимки показывают зафиксированные редакции продуктов; их нынешнее внешнее состояние не является объектом этого релиза.

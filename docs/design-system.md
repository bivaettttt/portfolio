# Дизайн-система

Фон `#f2f5fb`, чернила `#142039`, ссылочный сапфир `#2746be`. Независимые тёмные токены `#11192a`, `#eef3ff`, `#aebfff`. PT Serif используется для заголовков, Inter Variable для навигации, текста и технических подписей. Шрифты локальные и поддерживают кириллицу. Строки длинного текста ограничены 53–65 знаками.

Оболочка ограничена 1330 px. На desktop первый экран двухколоночный, на 690 px он складывается в одну колонку. Четыре ссылки мобильной навигации видны сразу. Стекло ослабляет фон в закреплённой навигации. Три слоя на hero иллюстрируют подход кандидата средствами CSS.

Каждая категория имеет собственный цвет папки. Личный кейс использует доменный акцент в обложке и рамке, исходные скриншоты не перекрашиваются. Требования оформлены нативным раскрытием, галерея — нативным диалогом с масштабом, а исходники доступны обычными ссылками. Внешние ссылки обозначены стрелкой. Фокус видим через токен `--focus`.

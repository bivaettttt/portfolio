# Стратегия содержания

Главная отвечает на вопросы о кандидате, цели и рабочем подходе. Кейс раскрывается в двух частях. Сначала проблема, статус, вклад, решения, правила и проверка. Затем реальный результат и ссылки на источники. В сценариях практики визуальный результат — явно обозначенная реконструкция, если оригинал закрыт.

Личные проекты позиционируются как учебные. Текст указывает, что автор поставил задачу и критерии приёмки, а в подготовке аналитики, кода и проверок использовался Codex. Проекты практики и хакатона маркируют личный и командный вклад отдельно. Успешное испытание локального стенда не переносится на промышленную эксплуатацию.

Каждый JSON в `src/content/projects/<категория>` проходит Astro Content Collections. Для изменения доказательств нужны новый SHA источника, проверка актуальности изображения, читабельные подписи в обеих языковых версиях и повторный link check. Операции в API Explorer извлечены из OpenAPI, формы отправки запросов нет.

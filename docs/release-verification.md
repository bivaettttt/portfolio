# Выпуск

Quality в GitHub Actions проверяет форматирование, Astro, статический пакет, ссылки, открытые медиа, типовые паттерны секретов и браузерные сценарии. Только проверенный запуск для `main` передаёт `dist/` в GitHub Pages. У старой публикации сохранены исходный коммит и история. Текущий статус виден в [Actions](https://github.com/bivaettttt/portfolio/actions/workflows/portfolio.yml) и в [публичном портфолио](https://bivaettttt.github.io/portfolio/).

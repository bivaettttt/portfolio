# Производительность

Lighthouse 13.6.0, локальная статическая production-сборка, мобильный профиль, Chrome headless. По одному последовательному контрольному прогону для каждого маршрута после завершения параллельной подготовки технических медиа.

| Маршрут | Performance | Accessibility | Best Practices | SEO | LCP | TBT | CLS |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Главная | 100 | 100 | 100 | 100 | 754 мс | 8 мс | 0 |
| Каталог | 100 | 100 | 100 | 100 | 755 мс | 0 мс | 0 |
| Кейс Flowent | 100 | 100 | 100 | 100 | 755 мс | 5 мс | 0 |

Диагностический замер главной во время параллельной установки и генерации медиа дал 70 за Performance и TBT 2 649 мс, при LCP 757 мс и CLS 0. Контроль снизил влияние фоновой работы. Лабораторные значения не заменяют полевой p75 и не позволяют оценить INP. [Web Vitals](https://web.dev/articles/vitals)

На страницах статический HTML. Основной JavaScript обслуживает темы, переходы, поиск по OpenAPI и диалоги. У снимков есть размеры и responsive WebP, у записей preload=none. Шрифты локальны. Пакет целиком около 8 МБ, значительная часть — медиа, загружаемые по мере открытия кейсов.

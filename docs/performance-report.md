В первом прогоне Flowent обнаружена ссылка оригинала без href в закрытом диалоге. Добавлен корректный адрес по умолчанию; открытие галереи по-прежнему задаёт адрес выбранного кадра. Повторный прогон выполнялся параллельно браузерным тестам, что могло повлиять на TBT; значение 95 сохранено в отчёте. Исходные JSON всех четырёх прогонов сохранены в `docs/evidence/v2/lighthouse/`. Это отдельная проверка Portfolio 2.0; результаты предыдущего релиза к ней не относятся.

HTML статический, шрифты локальны, JS обслуживает конкретные взаимодействия. Снимки имеют width/height, responsive srcset и lazy loading, видео — preload=none. PNG-оригиналы загружаются при исследовании в галерее. Презентационные WebP сохраняют lossless-кодирование технических подписей. Статический пакет около 24 МБ; он не загружается одной страницей. Чёткость медиа не заменена малым весом миниатюры.

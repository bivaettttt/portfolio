# Визуальное исследование

[Tuch и др.](https://research.google/pubs/the-role-of-visual-complexity-and-prototypicality-regarding-first-impression-of-websites-working-towards-understanding-aesthetic-judgments/) исследуют раннее впечатление по сложности и типичности. Следствие для портфолио — знакомая навигация и ограничение одновременных акцентов. [Reinecke и др.](https://dash.harvard.edu/entities/publication/73120378-cc85-6bd4-e053-0100007fdf3b) исследуют влияние сложности и цветности на первые оценки. [Reinecke и Gajos](https://www.eecs.harvard.edu/~kgajos/papers/2014/reinecke14visual.shtml) показывают варьирование предпочтений. Эти работы не позволяют обещать универсальную палитру или результат найма. Обложка и акценты остаются дизайнерским решением.

[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) и [Motion](https://developer.apple.com/design/human-interface-guidelines/motion) применены как рекомендации к слоям и непрерывности перехода. [WCAG 2.2](https://www.w3.org/TR/WCAG22/) задаёт критерии доступности. [NN/g](https://www.nngroup.com/articles/ux-design-portfolios/) помогает отделить процесс и вклад от галереи результатов. [IIBA](https://www.iiba.org/knowledgehub/the-business-analysis-standard/) даёт основу для контекста, участников, потребности, решения и ценности.

| Открытая страница | Наблюдение | Применение и риск |
| --- | --- | --- |
| [Apple](https://www.apple.com/) | Крупные самостоятельные главы с одной задачей | Один интерфейс на главу. Повторять размеры и вес медиа не требуется. |
| [Linear](https://linear.app/) | Логика продукта через последовательность экранов | Для трёх флагманов порядок по сценарию. Тонкие серые тексты требуют проверки контраста. |
| [Stripe](https://stripe.com/) | Технические детали и краткая продуктовая история живут рядом | Связи к контрактам. Сложные hero-градиенты здесь перегрузят чтение. |
| [Vercel](https://vercel.com/) | Полезный повторяемый ритм заголовков и разделителей | Иерархия глав и навигация. Карточки одного формата ослабят различие доменов. |
| [Framer](https://www.framer.com/) | Интерактивные фрагменты иллюстрируют отдельные действия | Небольшие демонстрации. Контент читается без анимаций. |
| [Figma](https://www.figma.com/) | Плотный продуктовый каталог группирует сценарии | Чёткие подписи вкладов. Яркая многослойность оставлена в референсе. |
| [Notion](https://www.notion.com/) | Текст и примеры выдерживают линейное чтение | Профиль остаётся коротким, подробности раскрываются в кейсе. |
| [21st](https://21st.dev/) | Каталог отделяет превью от действия | Разделяем снимок и просмотр оригинала. Внешний UI-код не переносим. |
| [Magic UI](https://magicui.design/) | Эффекты хорошо видны в независимых примерах | Используем краткий акцент перехода. Постоянный фон не нужен. |
| [React Bits](https://reactbits.dev/) | Демо движения отделено от документации | Эффект служит смене состояния. Избегаем canvas и тяжёлой гидратации. |
| [Motion Primitives](https://motion-primitives.com/) | Малые интеракции можно оценить по отдельности | Мягкое открытие слоёв. Контент присутствует в HTML. |
| [shadcn/ui](https://ui.shadcn.com/) | Повторяемость контролов и предсказуемые состояния | Нативные controls и dialog. Тему создаём по проекту. |
| [Siteinspire](https://www.siteinspire.com/) | Каталог быстро читается благодаря заголовкам и группам | Три визуально различимые папки, доступные как ссылки. |
| [Godly](https://godly.website/) | Обложки привлекают внимание раньше описания | Акцентировать реальные флагманские экраны, использовать краткое описание рядом. |
| [Lapa Ninja](https://www.lapa.ninja/) | Хорошо сравниваются примеры разного ритма | Отделять ссылку от обложки и избегать бесконечного ряда карточек. |

Сравнение основано на публичных страницах и документации. Трафик, конверсию и доступность сторонних сайтов не измеряли. UI UX Pro Max предложил контрастную редакционную композицию и полное DOM-чтение без эффектов. Палитра из каталога отклонена в пользу более спокойной системы. Из Vercel React Best Practices применён принцип ограничить клиентский JavaScript границами взаимодействий, Astro выдаёт HTML основного контента.

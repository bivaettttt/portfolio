# Движение

Переход страниц — Astro ClientRouter. Без JavaScript по ссылкам открываются те же статические документы. Папки сдвигают лист при hover и видимом фокусе, вызывая знакомое действие открытия. Сдвиги кнопок короткие, без задержки ответа. Шкала длительностей 180–350 мс с `cubic-bezier(.18,.74,.22,1)`. Диалог закрывается штатно с Escape. Движение не управляет видимостью содержания, а видео запускаются вручную.

`prefers-reduced-motion` отключает видимые переходы, прокрутка происходит сразу. CSS-слои hero остаются статичными. Движок анимаций для этих эффектов не требуется.
